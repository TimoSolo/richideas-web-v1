# richideas.co.za — static site (phase 1)

A static copy of the Rich Ideas Group website, cleaned up and fixed, that runs on
Cloudflare Pages (or any static host) with no server, database or WordPress.

The deployable site is the `site/` folder. Everything else is tooling and reference.

```
site/          the website (open site/index.html, or serve the folder)
scripts/       build.py (one-time WordPress mirror → site/), chrome.py (shared header/footer)
templates/     fragments build.py injects: forms, About page, fee table, home hero, insights
reference/     screenshots of the live WordPress site (before/) and this site (after/)
.github/       deploy workflow (push to main -> Cloudflare Pages)
```

## What changed from the WordPress site

Fixed
- Every Microsoft Forms / Jotform iframe is gone. Book a Meeting, Contact, Free Will, Review and
  the client Questionnaire are native HTML forms with validation, a honeypot and POPIA consent.
- About Us is a real page: the practice, the team (Terence, Salomé, Desireé), the six-step
  process, credentials.
- Contact Us has a working form instead of a pasted URL.
- Blogs is now Insights: a Substack signup, the latest 20 *Wealth Without Worry* issues and
  the 27 archive posts, all readable.
- Fee Structure publishes the plan fees from the 2026 Services Guide.
- Free Will is linked from the menu and footer.
- LinkedIn added to header and footer; newsletter signup on every page.
- Home hero copy carries the "families first" positioning, with a "Do We Fit" call to action,
  and the video has a poster instead of a black box.
- Cloudflare email obfuscation, theme demo pages, placeholder posts, search widgets, WordPress
  REST/RSS/emoji/speculation scripts, Contact Form 7, MediaElement, Primary Addon JS and the
  theme credit line are removed. All internal links are relative, so the site works at any path.

Kept as-is: the Bizberg theme + Elementor look, all real pages and their URLs, all 27 blog posts
(`/YYYY/MM/DD/slug/`), the Services Guide PDF, team photos, the video.

## Connecting things (all optional, one file)

Edit `site/assets/js/config.js`:

| Setting | Effect when set |
| --- | --- |
| `formEndpoint` | Forms POST JSON here. The shared relay in the 7vn.dev repo (`workers/forms`) emails submissions via Resend: set this to `https://forms.7vn.dev/richideas` (or the workers.dev URL) once it is deployed. Web3Forms/Formspree also work (`formAccessKey` for Web3Forms). Until set, forms open the visitor's email app with the details pre-filled, addressed to `formEmail`. |
| `bookingUrl` | Shows a "choose a slot" button on Book a Meeting (cal.com, Calendly…). |
| `ga4` | Loads Google Analytics 4 with that measurement id. Form and newsletter events are tracked. |

Newsletter forms submit to Substack's subscribe page with the email pre-filled; nothing to configure.

## Deploying

Cloudflare Pages, project `richideas`. Every push to `main` runs `.github/workflows/deploy.yml`, which needs two
repo secrets: `CLOUDFLARE_API_TOKEN` (Account > Cloudflare Pages: Edit) and `CLOUDFLARE_ACCOUNT_ID`.
`site/_headers` and `site/_redirects` are picked up automatically (old WordPress URLs redirect).

Any other host: upload the contents of `site/`.

## Editing

Pages are plain HTML in `site/`. The header, footer and newsletter band are generated by
`scripts/chrome.py`; after changing the nav or footer there, run `python3 scripts/chrome.py`
to re-stamp every page. `scripts/build.py` documents how `site/` was produced from the WordPress
mirror and is not needed for day-to-day edits.

Things still worth doing (not in phase 1): real online booking, client testimonials, the
executor-fee / cost-of-death calculators, and the new site and education content planned for
phase 2.

## Hosting on Cloudflare Pages

`site/_redirects` sends the old WordPress URLs that no longer exist (archives, feeds, the 2025
services PDF, placeholder pages) to their closest equivalent with a 301. `site/_headers` adds
`noindex` on `*.pages.dev` and `richideas.7vn.dev` only, so production stays indexable.
`wrangler.toml` points Pages at `site/`.

```
npx wrangler pages deploy site --project-name richideas    # first run creates the project
npx wrangler pages dev site                                 # local preview incl. redirects
```

Not covered: `?p=123` / `?page_id=45` links (Pages can't match query strings), and
`richideas.co.za` -> `www` (add a Cloudflare Redirect Rule on the zone at cutover). Also add each new
origin to `workers/forms/sites.json` in the 7vn.dev repo, or the forms will be rejected there.

### Test-site password

`functions/_middleware.js` asks for a password on every host except `richideas.co.za` and
`www.richideas.co.za`, so `richideas.7vn.dev` and `*.pages.dev` are gated and the live site never is.
The password is the `STAGING_PASSWORD` secret on the Pages project (username is ignored):

```
npx wrangler pages secret put STAGING_PASSWORD --project-name richideas
```
